# Lost & Found Management System

A web-based application that helps users report lost and found items, view submitted reports, and recover misplaced belongings.

## Features

- Report lost items.
- Report found items.
- Submit student and item details.
- View lost and found reports.
- Store records using MySQL.
- Maintain activity logs using database triggers.

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL

## Project Structure

```text
Lost-And-Found/

```

## Setup

1. Clone the repository.
2. Open the project folder.
3. Install dependencies:

```bash
npm install
```

4. Create the required MySQL database and tables.
5. Configure your local database credentials.
6. Start the server:

```bash
node server.js
```

7. Open `http://localhost:3000` in your browser.
